# 🎲 Говорю правильно — логопедическая игра

Веб-приложение для коррекции дислалии у детей 5–15 лет. Состоит из трёх страниц: главной, игры и панели исследования.

## 🚀 Как запустить

**Вариант 1 — просто открыть в браузере:**
1. Открой папку с `index.html`.
2. Дважды кликни на `index.html` — откроется в браузере.

**Вариант 2 — через локальный сервер (рекомендуется):**
Некоторые браузеры блокируют загрузку `data/*.json` через `file://`. Запусти локальный сервер:

- **Python:**
  ```
  python -m http.server 8000
  ```
  Потом открой `http://localhost:8000`

- **Node.js (если установлен):**
  ```
  npx serve
  ```

**Вариант 3 — залить на хостинг:**
Любой статический хостинг подойдёт: GitHub Pages, Netlify, Vercel, Cloudflare Pages. Просто перетащи папку.

## 🔊 Если нет русской озвучки

Игра использует Web Speech API — встроенный синтезатор речи браузера. Если русского голоса нет:

**Android:**
1. Настройки → Система → Язык и ввод → Синтез речи
2. Google → Установить голосовые данные → Русский
3. Или скачай [Google TTS из Play Маркета](https://play.google.com/store/apps/details?id=com.google.android.tts)

**iOS:**
1. Настройки → Универсальный доступ → Речь → Голоса
2. Русский → скачать нужный голос

**Windows:**
1. Параметры → Время и язык → Речь
2. Добавить голоса → Русский

**Mac:**
1. Системные настройки → Универсальный доступ → Устная речь
2. Системный голос → Русский

**Если озвучка не появляется в игре** — внутри игры есть кнопка **⚙️ Настройки → «Скачать русский голос»** с той же инструкцией.

## 🌍 Как добавить новый язык

1. Скопируй `data/i18n/ru.json` в новый файл, например `data/i18n/pt.json` (для португальского).
2. Переведи все значения (ключи не трогай — они должны остаться на английском).
3. Открой `js/core.js`, найди массив `LANGUAGES` в самом начале и добавь строку:

   ```js
   { code: 'pt', label: '🇵🇹 Português', name: 'Português' },
   ```

4. Всё. Язык появится в списке.

## 🃏 Как добавить новое задание

Открой `data/tasks_by_sound.json`. Например, добавь в массив `artic` новое упражнение:

```json
{
  "id": "novoe_zadanie",
  "name": "Новое задание",
  "desc": "Описание задания",
  "applies_to": ["Л", "Р"],
  "img": "images/tasks/common/novoe.png",
  "reps": {"5":3, "6":4, "7":5, "8":6, "9":6, "10":6, "11":6, "12":6, "13":7, "14":7, "15":7}
}
```

Поля:
- `id` — уникальный идентификатор (латиницей, без пробелов)
- `name` — название задания
- `desc` — текст задания
- `applies_to` — массив звуков, к которым подходит (`["Л", "Р", "С", "Ш", "Ж"]` или `["all"]` для всех)
- `img` — путь к картинке (если нет — оставь `""`)
- `reps` — сколько повторять для каждого возраста

Картинку положи в `images/tasks/common/`. Если её нет — подставится `_placeholder.svg`.

## 💾 Бэкап данных

Все данные хранятся **в браузере** (localStorage). Чтобы не потерять:

1. **⚙️ Настройки → «Скачать все данные»** — сохранится JSON-файл.
2. На другом устройстве: **⚙️ Настройки → «Восстановить из файла»** — выбери этот JSON.

**Важно:** данные **не синхронизируются** между устройствами автоматически. Делай бэкап перед сменой устройства.

## 🗣 Распознавание речи

В режиме задания есть блок **«Проверить произношение»**:
1. Ребёнок нажимает **🎤 Проверить произношение**.
2. Говорит в микрофон.
3. Система сравнивает услышанное со словами задания.
4. Показывает ✅ или ⚠️.

Также можно **записать голос** для самоконтроля и прослушать его.

**Работает не во всех браузерах.** Лучше всего — в Chrome, Edge, Safari. В Firefox — не поддерживается.

## 🐛 Известные проблемы

| Проблема | Причина | Решение |
|---|---|---|
| Не загружаются карточки | Браузер блокирует JSON через `file://` | Запусти через локальный сервер (см. выше) |
| Нет русской озвучки | Не установлен русский голос | См. раздел «Если нет русской озвучки» |
| Не работают картинки | Файлы не положены в `images/tasks/` | Ничего страшного — подставится заглушка |
| Не сохраняются данные | Режим инкогнито | Используй обычный режим браузера |
| Не переносятся данные | Разные браузеры/устройства | Скачай бэкап через ⚙️ и восстанови |
| Микрофон не работает | Нет разрешения | Разреши доступ в настройках браузера |
